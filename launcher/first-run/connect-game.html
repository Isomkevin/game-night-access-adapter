Any browser game

Connect the tab you are playing

  1. Open your game in Chrome (or Edge).
  2. Click inside the game so that tab is focused.
  3. Open the Game Night Access Adapter extension popup → Use this tab.
  4. If keys feel wrong, open Setup → Customize and remap actions or key codes.
  5. For phone, camera, or voice, open the control hub while Game Night is running in the tray.
