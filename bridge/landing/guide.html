Game Night Tutorial

For everyone — no coding

From download to playing your game

Game Night helps you control any keyboard-driven browser game with phone tilt, camera, voice, or large on-screen buttons. This page walks through install, first setup, and everyday use.

Step 1

Install two pieces

  1. Chrome extension — install Game Night Access Adapter from the Chrome Web Store (search “Game Night Access Adapter”). If the Store listing is not live yet, use the desktop app’s Extension setup coach (Load unpacked) once.
  2. Game Night desktop app — download the installer for your computer (Windows, Mac, or Linux) from the project Releases page, then run it. You should see a small Game Night icon in the system tray / menu bar.

You do not need Git, Node, or a terminal. The desktop app starts the access bridge for you.

Step 2

First-time setup (about 5 minutes)

  1. Open Game Night from the Start Menu / Applications (or wait for login autostart).
  2. Pin the extension to Chrome’s toolbar (puzzle piece → pin Game Night Access Adapter).
  3. Click the extension → Setup. Follow Welcome → Choose controls → Customize → Ready. Change any mapping you like; nothing requires editing code.
  4. Open your browser game in Chrome (any site that uses the keyboard).
  5. Click inside the game, open the extension popup, click Use this tab.
  6. Open the control hub and pick phone, camera, voice, or use the on-screen pad in the popup.

Toolbar badge ON means the bridge is connected. Badge OFF still allows the on-screen pad.

Step 3

Day-to-day use

  1. Make sure Game Night is running (tray icon). Use Start at login so it comes back after reboot.
  2. Open Chrome and your game.
  3. If controls don’t reach the game, click the game page → extension → Use this tab again.
  4. Open the hub for phone / camera / voice, or use the popup pad.
  5. When something sticks, use Stop all inputs in the popup.

Tray menu cheat sheet

  • Open Game Night — this home / status site
  • Control hub — choose how you play
  • Extension setup — only if Chrome disabled the extension
  • How to connect a game — short reminder for Use this tab
  • Restart bridge — if phone/camera/voice pages won’t load
  • Quit — stops the bridge until you open Game Night again

Controls

Pick what fits your body

  • On-screen pad — large buttons in the extension popup. Works even if the bridge is off.
  • Phone — same Wi‑Fi as the computer; open the phone page from the hub; allow motion sensors.
  • Camera / head — allow the webcam; calibrate; prefer the in-game camera overlay so tracking keeps running.
  • Voice — short spoken commands; allow the mic while listening.

Remap anything later in Setup → Customize. Export a backup JSON if you like.

Help

If something goes wrong

  • Nothing moves in the game — click the game canvas, confirm Use this tab, try the popup pad.
  • Badge stays OFF — tray → Restart bridge; wait a few seconds; Reconnect in the popup.
  • Phone can’t open the page — same Wi‑Fi (not guest Wi‑Fi); use the LAN link shown in the hub.
  • After a Chrome update — re-enable the extension; tray → Extension setup if needed.
  • Port busy message — follow the on-screen note, or Restart bridge.
