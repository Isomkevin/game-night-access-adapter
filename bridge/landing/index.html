Co-designed with Justin Machogu · Built for Chrome + LibreCorsa

The problem

Browser games assume a mouse, chords, and continuous pace.

That locks players with motor access needs out of racing with friends and family. Justin’s ask was simple and non-negotiable: fully remappable controls that match the movements he can use — on your laptop, with software only.

How it works

Accessible inputs become the keys the game already hears.

We do not rewrite LibreCorsa. A local bridge and Chrome extension translate your inputs into keyboard codes during the driving phase.

  1. 1

    Sense

    Phone, camera, voice, or the extension pad emit logical actions.

  2. 2

    Bridge

    A WebSocket hub on this host fans events to the extension.

  3. 3

    Remap

    Your profile maps source:action → game action → key code.

  4. 4

    Drive

    Synthetic keydown/keyup reach LibreCorsa while you are on track.

Justin’s core need

Change mappings without editing code.

Extension Setup walks Welcome → Choose → Customize → Ready. Profiles live in Chrome storage and export as JSON. Defaults match LibreCorsa’s own bindings.

  • 48px touch targets and high-legibility type (Atkinson Hyperlegible)
  • Hold vs latch modes; Stop all inputs when something sticks
  • Works on Justin’s — no USB gamepad or ADB

Get started

From zero to driving with accessible controls.

  1. Run LibreCorsa locally at localhost:3000 or open the hosted build, then enter a driving session.
  2. Load the Chrome extension unpacked from extension/ — see the onboarding guide.
  3. Use this bridge for phone, camera, or voice — open the control hub, then focus the game canvas.
