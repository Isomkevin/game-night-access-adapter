Game Night Access Adapter

Play your way

Built with co-designers

Race with the controls that work for you

Game Night Access Adapter lets you play browser games (LibreCorsa by default) without relying on a conventional keyboard or mouse. Use on-screen buttons, your phone, head movement, or voice — then remap anything so it matches how you move.

You do not need to understand developer tools. We will walk through each step.

Choose how you want to control the game

Pick a starting method. You can change this later and combine methods.

Set up your controls

Follow these short steps.

    Customize your controls

    Choose a game action for each input. Changes save on this device. Use Test to send a short pulse through the real control path (focus the game while driving).

    Advanced: match keys rebound in the game

    Change these to match the keys your game expects. Defaults match LibreCorsa.

    Ready to play?

    Check each item, then open the game and use your controls while driving.

      Tip: pin the extension, then use the popup for large on-screen buttons, latch mode, and Stop all inputs.
