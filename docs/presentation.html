Game Night Access Adapter

Play together without assuming fast fingers.

Software-only remappable inputs — camera, voice, phone, and on-screen pad — mapped onto the keys a browser game already understands.

Co-designed with Justin Machogu No extra hardware LibreCorsa PoC · pin any game tab

The problem

Gaming should not depend on one way of moving.

  • Browser games assume a mouse, multi-key chords, and continuous pace — locking out players with motor access needs from shared game nights.
  • Justin Machogu: wheelchair user with limited finger mobility; loves racing and FIFA. Stock bindings don’t match how he moves.
  • Core ask: fully remappable controls — change mappings without editing code.

Design constraint

Specialized adaptive hardware is expensive and hard to bring to a friend’s house.

Hard rule for this PoC: no external hardware

Phone = a LAN web page. Works on Justin’s MacBook without USB or ADB.

The solution

One adapter. Multiple ways to play.

We don’t rewrite the game. Accessible inputs become logical actions, get remapped by the player, and inject as keyboard codes during driving.

phone:tiltLeft → Steer left camera:yawRight → Steer right voice:boost → Space demo:throttle → KeyW

The remapping experience

Change how you move — without touching game code.

  • Setup walkthrough: Welcome → Choose → Customize → Ready.
  • Profiles in chrome.storage; export / import as JSON.
  • Defaults match LibreCorsa: A/D steer, W/S pedals, Space boost.
  • Injection only matters in the driving phase.

LibreCorsa listens on window and does not check isTrusted — synthetic keys work.
