Game Night Access Adapter

Play together without assuming fast fingers.

Remappable camera, voice, and phone inputs for LibreCorsa — software only, laptop + phone.

Co-designer: Justin Machogu · Due Saturday 7 Nov

Problem + co-designer

Browser games assume mouse, chords, and continuous pace.

  • Justin: wheelchair user, limited finger mobility; loves racing / FIFA
  • Core ask: fully remappable controls
  • Already remaps keys and uses voice at work — we mirror that for games
  • Hard constraint: no external hardware
Architecture

Inputs → bridge → extension → game keys

Camera · Voice · Phone · Demo pad Local bridge WebSocket :18765 Chrome extension remap table LibreCorsa keyboard codes (KeyW/A/S/D…)
Why LibreCorsa + software phone

One open-source racer as proof of concept.

  • Next.js + Three.js F1-style game Justin can evaluate
  • Phone = LAN web page (gyro + large buttons), not USB/ADB
  • Works on Justin’s MacBook; camera is the redundant fallback
  • Universal adapter later — PoC first
Live demo

Show remap, then drive.

  • Load unpacked extension → Options → change one binding
  • Drive with demo pad, phone tilt, or head tracking
  • Focus the game canvas; driving phase only
  • Badge demo = offline pad; ON = bridge connected
Toolkit integration

Use and extend the AI for Accessibility Toolkit.

  • Voice via toolkit Controller → shared voice:* protocol
  • Example pack: examples/game-night-librecorsa/ on the fork
  • Upstream PR compare link in README / toolkit-contribution docs
  • Issues filed from Justin’s testing (latency, grammar, macOS)
What’s next

Honest PoC → universal adapter vision.

  • Ship Saturday: working public repo, docs, video, presentation
  • Next: more games via remap profiles; tighter toolkit Controller
  • Keep redundancy: camera ↔ phone ↔ voice ↔ keyboard
