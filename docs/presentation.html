Game Night Access Adapter

Play together without assuming fast fingers.

Remappable camera, voice, phone, and on-screen inputs for LibreCorsa — software only, laptop + phone, no game rewrite.

Co-designed with Justin Machogu AI for Accessibility challenge Public PoC

The problem

Browser games assume a mouse, chords, and continuous pace.

  • That locks players with motor access needs out of racing with friends and family.
  • Justin: wheelchair user, limited finger mobility; loves racing and FIFA — stock bindings don’t match how he moves.
  • Core ask: fully remappable controls — change mappings without editing code.

Hard constraint

No extra hardware. The phone is a LAN web page, not a USB gamepad or ADB dongle — so it works on Justin’s macOS MacBook.

Why this matters

Game night should not require the same hands as a keyboard warrior.

Mirror what Justin already does at work — remap keys and use voice — into the games he wants to play with people he cares about.
  • Who: players with motor access needs; friends & family hosts.
  • Where it starts: one open-source browser racer judges can try today.
  • Why now: browser sensors + MV3 extensions + shared accessibility toolkit.

Our solution

Accessible inputs become the keys LibreCorsa already hears.

We do not rewrite the game. A local bridge and Chrome extension translate logical actions into KeyboardEvent.code during the driving phase.

phone:tiltLeft → Steer left camera:yawRight → Steer right voice:boost → Space demo:throttle → KeyW

Product experience

Remap once. Drive with the body movement that works.

  • Extension Setup: Welcome → Choose → Customize → Ready.
  • Profiles in Chrome storage; export / import as JSON.
  • Popup pad works offline for smoke tests (badge OFF).
  • Pin any http(s) game tab with Use this tab.

Core features

Four ways in. One remap table. Redundancy by design.

Available

Phone controller

Tilt to steer; large throttle, brake, and boost on the same Wi‑Fi.

Experimental

Head & vision

MediaPipe head / face / hand gestures — calibrate first; nothing uploaded.

Experimental

Voice commands

Short spoken taps (“go”, “boost”, “pause”) via toolkit Controller path.

Works offline

On-screen pad

Hold or latch in the extension popup; Stop all inputs when something sticks.

How it works

Sense → bridge → remap → drive.

  1. 1

    Sense

    Phone, camera, voice, or the extension pad emit logical actions.

  2. 2

    Bridge

    WebSocket hub on :18765 fans events to the extension.

  3. 3

    Remap

    source:action → game action → key code in the player’s profile.

  4. 4

    Drive

    Synthetic keydown/keyup reach LibreCorsa while on track.

Technology & innovation

What makes the PoC technically interesting.

  • Extension Chrome MV3 remap UI, session pin, content-script injection (+ MAIN-world hook fallback).
  • Bridge Node HTTP + WebSocket fan-in; serves phone, camera, voice, and this landing.
  • Vision On-device MediaPipe; optional in-game camera dock so focus loss doesn’t drop inputs.
  • Toolkit Voice through AI for Accessibility Toolkit Controller; upstream example PR #55.
  • Insight LibreCorsa listens on window and does not check isTrusted — synthetic keys work in driving phase.

Differentiation

Software adapter, not another controller to buy.
